🔮 Salem Voice Game Master
โปรแกรมผู้ดำเนินเกม (Game Master) อัตโนมัติด้วยเสียงพูดภาษาไทย สำหรับบอร์ดเกม Salem 1692 กรณีที่ผู้เล่นทุกคนอยากร่วมเล่นโดยไม่มีใครต้องเป็น GM
📖 เกี่ยวกับโปรแกรม
Salem 1692 เป็นบอร์ดเกมแนว social deduction ที่ต้องมี Game Master คอยควบคุมเฟสกลางคืน บอกให้แม่มดลืมตา/หลับตา และนับเวลาเลือกเป้าหมาย ปัญหาคือถ้าทุกคนอยากเป็นผู้เล่น จะไม่มีใครคุมเกม
โปรแกรมนี้ใช้ Text-to-Speech ภาษาไทย (เสียง Kanya จาก macOS) มาทำหน้าที่ GM แทน เพียงรันสคริปต์แล้วฟังคำสั่ง ทุกคนก็สนุกกับเกมได้พร้อมกัน
✨ ฟีเจอร์

🎙️ ออกคำสั่งเป็นเสียงภาษาไทย
🌙 รองรับเฟสกลางคืนเต็มรูปแบบ (แม่มดเลือกฆ่า + Constable ปกป้อง)
⏱️ นับถอยหลังให้ผู้เล่นเลือกเป้าหมายอัตโนมัติ
🎴 มีโหมดเริ่มเกม (วาง Black Cat) แยกจากกลางคืนปกติ
🛡️ รองรับกรณีที่ Constable ตายไปแล้ว (โหมด nightnocon)

🔧 ความต้องการของระบบ

macOS (เพราะใช้ NSSpeechSynthesizer ผ่าน nsss driver)
Python 3.7+
เสียงภาษาไทย Kanya ติดตั้งใน System Preferences → Accessibility → Spoken Content → System Voice → Manage Voices → ดาวน์โหลด Kanya (Thai)

📦 การติดตั้ง
bash# Clone repo
git clone https://github.com/yourusername/salem-voice-gm.git
cd salem-voice-gm

# ติดตั้ง dependency
pip install pyttsx3
🚀 วิธีใช้งาน
bashpython salem_gm.py
โปรแกรมจะเริ่มทำงานทันที โดยปัจจุบันตั้งค่าให้รันฟังก์ชัน nightnocon() (กลางคืนแบบไม่มี Constable)
หากต้องการเรียกฟังก์ชันอื่น ให้แก้บรรทัดสุดท้ายของไฟล์:
pythonstart()        # เริ่มเกม - แม่มดวาง Black Cat
night()        # กลางคืนปกติ - มีทั้งแม่มดและ Constable
nightnocon()   # กลางคืน - กรณี Constable ตายแล้ว
🎮 ลำดับเหตุการณ์ในแต่ละฟังก์ชัน
start() — เริ่มเกม

ทุกคนหลับตา (รอ 5 วิ)
แม่มดลืมตา
แม่มดเลือกวาง Black Cat (นับถอยหลัง 15 วิ)
ทุกคนลืมตา

night() — กลางคืนปกติ

ทุกคนหลับตา (รอ 5 วิ)
แม่มดลืมตา → เลือกฆ่า (นับถอยหลัง 20 วิ)
แม่มดหลับตา (รอ 5 วิ)
Constable ลืมตา → เลือกปกป้อง (นับถอยหลัง 15 วิ)
ทุกคนลืมตา

nightnocon() — กลางคืนไม่มี Constable

ทุกคนหลับตา (รอ 5 วิ)
แม่มดลืมตา → เลือกฆ่า (นับถอยหลัง 20 วิ)
ทุกคนลืมตา

🛠️ โครงสร้างโค้ด
salem_gm.py
├── start()         # เฟสเริ่มเกม
├── night()         # เฟสกลางคืน (มี Constable)
└── nightnocon()    # เฟสกลางคืน (ไม่มี Constable)
